# Decision coverage and experiment matrix

The user requests a comprehensive set of decision-informing experiments,
execution, results in issue #518 or child issues, then swarm-model-refinement.
This is finite coverage of every current decision and its material factors,
not an assertion that all possible GitHub states/configurations are enumerable.
Existing exact evidence is reused where it already answers a question; fresh
controls target unresolved premises, negative cases and interactions.

The campaign uses disjoint synthetic fixture namespaces. The local coordination
profile retains writer allocation and privacy/authority limits. Every lane plan precedes that lane's first
mutation. Adaptations retain the original attempt, reason and outcome oracle.
No production migration is built merely to make a prototype pass.

## Coverage and completion

The 19-question audit maps individual decisions to
these families; it is a dated snapshot and must be refreshed at final integration.
The scope includes technically relevant alternatives without requiring a new
service, archive format, hosted history product or production GHerrit migration.
Those would create additional products rather than directly test a premise.

Each case must end as performed with actual observations, reused with exact
evidence, or unavailable with a concrete missing premise. Model failures, driver
failures, API refusals, unknown outcomes and unexercised premises remain distinct.
Process death is not machine power-loss validation. A time window or successful
finite trace is not a future-write fence. No experiment supplies user priorities.

Before final publication/refinement: collect exact source/evidence identities;
audit important oracles and preserved failures; reconcile every temporary
permission/workflow/environment and active native request; independently observe
queues and required final state; publish synthetic-only evidence and read back
issue/results; then run a fresh swarm under the new exposed evidence. Retain
unavailable provider/human/browser guarantees in that design review.
