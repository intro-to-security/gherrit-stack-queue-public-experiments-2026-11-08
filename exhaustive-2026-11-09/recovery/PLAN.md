# Local recovery and migration evidence

This lane writes only this directory. It uses new disposable Git repositories,
Python's standard library and a local provider emulator. It never replays a
historical driver. Historical L01–L30 results remain evidence for those exact
artifacts, including their failures. No production GHerrit implementation,
hosted provider ordering, human preference or machine-power-loss claim follows
from this lane.

## Concrete candidates

The strict control refuses every overlapping hosted write while an older native
effect remains unresolved. It permits retained local successors and demonstrably
disjoint work, preserving the older operation's captured input.

The ordinary-import control uses the incorporated hosted range as baseline and
the current accepted local result as local input. It has no separate confirmed
intent guard. The late-reversal case must expose its silent edit loss.

The detected-drift candidate allows an explicitly accepted same-order amendment
after a known lower-prefix landing, retaining each older operation's exact input,
scope and unknown outcomes. It excludes reorder, regrouping, landing, queue and
base/lifecycle changes during overlap. Before incorporating any changed hosted
range in that scope, it requires explicit per-change acceptance: retain current
intent through a reviewed restoration proposal, accept the hosted edit as new
intent, or leave a conflict unresolved. A coherent observation alone cannot make
that decision. The proposal merges the retained old operation input, latest
accepted intent and new observed range on scratch objects; a conflict never
becomes an accepted result. It cannot attribute a remote edit to an old writer.

Authored submission/archive, incorporated hosted range, accepted intent/result,
current captured source and newly observed hosted range remain distinct. A fresh
local acceptance never completes an older request or replaces its captured input.
Drift detection occurs on a connected, coherent observation; temporary wrong
hosted state, missed ABA/transient revisions, conflicts and manual decisions are
explicit costs. A structural reversal may terminalize a canonical review, so the
candidate refuses it and does not promise a bytes-only repair.

Each case ends in an explicit disposition with source, raw command evidence and
domain bounds. Unexpected failures stay retained. New runs get a fresh directory;
the final run records source hashes. Runtime probe: Docker is shared OrbStack
29.4.0/aarch64 with existing Python/Ubuntu images; no owned guest emulator is
evidenced. No container or VM has been started, stopped or changed.

Bounds: at most two concurrent Python children, per-child waits at most 15
seconds, small Git trees, model event depth at most seven, no installation or
large image allocation. Filesystem process interruption is distinct from device
power loss; persistence choices in a model are assumptions, not observations.

failed: `%B` pretty output supplied a newline that became part of the recreated
message. The corrected importer reads the raw commit-object message instead.
